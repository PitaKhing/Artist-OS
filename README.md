# ArtistOS

ArtistOS is a web application designed to help independent artists manage their music careers from one central platform.

## Project Goal

ArtistOS aims to reduce the need for artists to manage their releases, content, tasks, and performance data across multiple disconnected tools.

## MVP Features

- Dashboard
- Music Release Management
- Content Planner
- Task Management
- Basic Analytics

## Target Users

Independent musicians and artists who want a simple way to organize and manage their music careers.

## Project Status

In Development

This project is being built from scratch and documented publicly as part of my journey combining software development and music.

## Planned Technology

- Frontend: React / Next.js
- Styling: Tailwind CSS
- Backend: Next.js
- Database: PostgreSQL
- ORM: Prisma
- Authentication: Auth.js
- Deployment: Vercel
